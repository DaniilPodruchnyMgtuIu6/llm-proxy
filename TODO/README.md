# TODO / SDD changes

Здесь фиксируем **планы изменений** до и во время реализации — как audit trail (в духе OpenSpec/SDD).

## Конвенция

```
TODO/
  README.md                          ← этот файл
  active/
    YYYY-MM-DDTHHMMSS-<slug>/        ← активный change
      plan.md                        ← цель, дизайн, решения
      tasks.md                       ← чеклист
  archive/
    YYYY-MM-DD-<slug>/               ← завершённые changes (не правим)
```

Правила:

1. Перед новой фичей создаём папку в `active/` с **датой и временем** фиксации.
2. Во время работы обновляем только `tasks.md` (чекбоксы).
3. После мержа/деплоя переносим папку в `archive/YYYY-MM-DD-<slug>/` — архив иммутабелен.
4. Living docs (`README.md`, `docs/*`) обновляем по ходу; план в TODO остаётся историей «что решили и почему».
