# Документация провайдеров

Здесь лежит карточка **каждого** бесплатного/платного источника LLM.

Цель: не искать лимиты и особенности заново — смотри файл провайдера перед работой и при ошибках `429` / `404`.

## Как вести карточку

Для нового источника копируй [`_TEMPLATE.md`](./_TEMPLATE.md) → `docs/providers/<name>.md` и заполни все секции.

Обязательно фиксируй:

- как получить доступ (ключ, OAuth, без ключа);
- как ходим в API (URL, формат);
- бесплатные лимиты (RPM / RPD / TPM / неделя) и **когда сбрасываются**;
- какие модели реально работают на free (проверено у нас);
- переменные `.env`;
- дату последней проверки.
